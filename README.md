# Сервис синхронизации файлов

Программа для синхронизации файлов между локальной папкой и Яндекс.Диском.

## Требования

Python 3.8+
Библиотека requests (устанавливается через pip).

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости:
   pip install -r requirements.txt

3. Получите OAuth-токен для Яндекс.Диска в Яндекс.Полигоне.
4. Откройте файл config.ini и заполните поля:
   - local_folder — путь к вашей локальной папке.
   - remote_folder — имя папки на Яндекс.Диске (должна существовать).
   - token — ваш токен доступа.
   - sync_period — период синхронизации в секундах.
   - log_file — имя файла для логов.

## Запуск

python main.py

## Как это работает

Программа запускается в фоновом режиме и каждые N секунд проверяет локальную папку.
Если появляется новый файл — он загружается на Яндекс.Диск.
Если файл изменяется — он перезаписывается в облаке.
Если файл удаляется — он удаляется из облака.

Все действия записываются в лог-файл (по умолчанию sync.log).
